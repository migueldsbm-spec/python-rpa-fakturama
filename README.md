# Python RPA Automation - Fakturama ERP

This project is an RPA (Robotic Process Automation) developed with Python and PyAutoGUI to automate product registration inside the Fakturama ERP system.

## Features
- Opens Fakturama automatically
- Creates products automatically
- Reads product data from Excel
- Uploads product images automatically
- Saves products without manual interaction

## Technologies Used
- Python
- PyAutoGUI
- Pandas
- Pyperclip

## Objective
The goal of this project was to practice desktop automation, process optimization, and integration between Python and ERP systems.
